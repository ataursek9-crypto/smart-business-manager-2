--------------------------------------------------------------------------------
১. "SmartBusinessManager_Export.zip" আনজিপ (Extract) করার পর আপনি এই ফোল্ডারে 
   "SmartBusinessManager.apk" ফাইলটি দেখতে পাচ্ছেন।

২. "SmartBusinessManager.apk" ফাইলটি আপনার ফোনে নিন (USB ক্যাবল, হোয়াটসঅ্যাপ, 
   গুগল ড্রাইভ অথবা শেয়ারইট/ব্লুটুথের মাধ্যমে)।

৩. ফোনের "Files" বা "Downloads" অ্যাপে গিয়ে "SmartBusinessManager.apk" ফাইলে ট্যাপ করুন।

৪. যদি আপনার ফোন "Install unknown apps" (অজানা উৎস থেকে ইনস্টল)-এর অনুমতি চায়:
   - "Settings"-এ ক্লিক করুন।
   - "Allow from this source" চালু করুন।
   - ব্যাক (Back) এসে "Install" বাটনে ট্যাপ করুন।

৫. ইনস্টলেশন সম্পন্ন হলে "Open"-এ ট্যাপ করে আপনার স্মার্ট বিজনেস ম্যানেজার ব্যবহার শুরু করুন।
