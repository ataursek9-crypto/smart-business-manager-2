# Smart Business Manager - APK ডাউনলোড ও এক্সপোর্ট নির্দেশিকা

## ১. Google AI Studio থেকে সরাসরি APK ডাউনলোডের সঠিক পদ্ধতি (সবচেয়ে সহজ)

Google AI Studio ক্লাউড রান এনভায়রনমেন্টে ওয়েব ব্রাউজারের সরাসরি HTTP লিংক কাজ করে না কারণ ওয়েব পোর্টটি সরাসরি অ্যান্ড্রয়েড এমুলেটর স্ট্রিমিংয়ের সাথে সংযুক্ত থাকে। কিন্তু **AI Studio-এর নিজস্ব ফাইল এক্সপ্লোরার ও এক্সপোর্ট টুল দিয়ে ১০০% নিশ্চিতভাবে ফাইল ডাউনলোড করা যায়**:

### পদ্ধতি ১: ফাইল এক্সপ্লোরার থেকে ১-ক্লিকে সরাসরি ডাউনলোড (প্রস্তাবিত)
1. AI Studio ইন্টারফেসের **বাম পাশের ফাইল ম্যানেজার (File Explorer / File Tree)**-এ যান।
2. সেখানে ফাইল তালিকার মূল ফোল্ডারে (Root-এ) দেখতে পাবেন:
   - `Smart_Business_Manager.apk` (সাইজ: ~৩১ MB)
   - অথবা `APK/app-debug.apk`
3. ফাইলের নামের ওপর **Right-Click (ডান বাটন ক্লিক)** করুন অথবা পাশে থাকা **থ্রি-ডট (⋮)** মেনুতে চাপ দিন।
4. **"Download"** অপশনে ক্লিক করুন।
5. মুহূর্তের মধ্যে মূল APK ফাইলটি সরাসরি আপনার ডিভাইসে ডাউনলোড হয়ে যাবে।

---

### পদ্ধতি ২: AI Studio-এর "Export as ZIP" ব্যবহার করে ডাউনলোড
1. AI Studio স্ক্রিনের উপরে ডানদিকের কোণায় **Settings / Three dots (⋮)** মেনুতে ক্লিক করুন।
2. **"Export project as ZIP"** (অথবা "Download Project") বাটনে চাপ দিন।
3. সম্পূর্ণ প্রজেক্টটি জিপ হিসেবে ডাউনলোড হবে।
4. জিপটি আনজিপ করলে মূল ফোল্ডারে সরাসরি পেয়ে যাবেন:
   - `Smart_Business_Manager.apk`
   - `APK/app-debug.apk`
