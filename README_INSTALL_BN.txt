=====================================================
Smart Business Manager - Debug APK Installation Guide
=====================================================

অ্যাপের নাম: Smart Business Manager
প্যাকেজ নাম: com.aistudio.smartbiz.mgr
ফাইল নাম: app-debug.apk
বিল্ড টাইপ: Debug APK (Pre-signed with debug keystore)

কিভাবে মোবাইলে ইনস্টল করবেন:
১. এই ZIP ফাইলটি আনজিপ (Extract) করলে সরাসরি "app-debug.apk" ফাইলটি পাবেন।
২. "app-debug.apk" ফাইলটি আপনার অ্যান্ড্রয়েড মোবাইলে নিন (USB Cable, WhatsApp, Google Drive বা সরাসরি ফোনের ডাউনলোড ফোল্ডারে)।
৩. ফাইলটিতে ট্যাপ করুন।
৪. যদি Android সতর্কবার্তা দেখায় "Install unknown apps" বা "Unknown Sources", সেটি Allow / Enable করুন।
৫. "Install" বাটনে ক্লিক করলেই Smart Business Manager সফলভাবে ইনস্টল হয়ে যাবে।

নতুন আপডেটে যা যুক্ত ও ঠিক করা হয়েছে:
- মোবাইল নম্বর দিয়ে Firebase Real SMS OTP রেজিস্ট্রেশন।
- Google Sign-In দিয়ে দোকান রেজিস্ট্রেশন ও বিদ্যমান দোকান রিস্টোর।
- TRIAL সাবস্ক্রিপশন পারমিশন ফায়ারস্টোর সিকিউরিটি রুলসে ফিক্স।
- সুপার অ্যাডমিন ড্যাশবোর্ডে নতুন রেজিস্ট্রেশন হওয়া দোকানের উপস্থিতি।
- সম্পূর্ণ অফলাইন-অনলাইন ডুয়াল সিঙ্ক (Room + Firestore)।
